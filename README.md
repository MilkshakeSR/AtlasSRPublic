# Atlas

A personal AI assistant for the Mac, powered by Claude, with an optional local mode using Ollama.

## Download

Get **Atlas.dmg** from the [latest release](../../releases/latest). It needs macOS 14 or later and runs on Apple silicon and Intel Macs.

## Install

1. Open `Atlas.dmg` and drag **Atlas** to **Applications**.
2. Open Atlas. macOS will say it can't verify the app, because it isn't notarized by Apple.
3. Go to **System Settings > Privacy & Security**, scroll down, and click **Open Anyway** next to Atlas.
4. Add a Claude API key from [platform.claude.com](https://platform.claude.com/settings/keys), or use a local model with [Ollama](https://ollama.com).

## Features

- Streaming chat with Markdown, code highlighting, tables and attachments
- Quick Ask: press ⌥⇧Space anywhere for a floating panel
- Follow-up suggestions, study tools, read aloud and PDF export
- Pin, archive, rename and share chats through links
- Your chats stay on your Mac
